Generador de Estrategias BSC con IA
Esta aplicación en Streamlit permite a los estudiantes subir un archivo Excel con su Balanced Scorecard y generar estrategias manuales y con IA.
Uso
1.	Sube un archivo Excel con columnas: Perspectiva, Objetivo, Meta, Indicador, Iniciativa.
2.	Selecciona una fila.
3.	Genera estrategias con IA consumiendo el backend en Hugging Face Spaces.
